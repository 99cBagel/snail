# snail

**Professional Knowledge Base**
A2A access — Connect with Agent, then Ask Anonymously

A platform of individual professional knowledge spaces at **snail.keeg.uk**.
Each space is one principal's knowledge base, or one topic:

- `snail.keeg.uk/<space>` — the space's page
- `snail.keeg.uk/<space>/mcp` — the space's MCP hook (agent-to-agent access)

Spaces are maintained manually by the operator. A handful of tenants, by design.
